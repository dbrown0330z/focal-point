# Admin overview

The admin area is separate from the member portal and uses a different visual style so you always know which context you're in. Access it via the **Admin** link in your member navigation, or go directly to `yourclub.com/admin`.

## Sections at a glance

| Section | What it does |
|---|---|
| **Dashboard** | Quick stats and pending actions |
| **Club Basics** | Core settings: name, timezone, competition defaults |
| **Members** | Approve, view, and manage all member accounts |
| **Competitions** | Create and run monthly photo competitions |
| **Judges** | Manage judge tokens for external judges |
| **Content & Pages** | Edit the homepage, custom pages, navigation and galleries |
| **Resources** | Upload documents and files for members |
| **Communication** | Send email messages to members |

## Key things to set up first

1. **Club Basics → General** — set your club name, location, and contact email
2. **Club Basics → Competition defaults** — configure scoring rules, submission limits, and judging settings
3. **Content & Pages → Homepage** — customise what members see on the home page
4. **Content & Pages → About** — fill in the club details panel

> **Tip:** The admin area is only visible to users with the Admin role. New sign-ups default to no role until an admin approves them.
